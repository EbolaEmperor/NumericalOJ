# 论文摘要挑战赛：公开题目描述

请为您的 Claude Code 配置一个 skill：`sketcher`，用于自动阅读数学论文，并生成一份中文的 `.tex` 文件，包含：

- 论文的背景
- 论文的问题模型、符号说明
- 论文的主要结论

请使用您的 skill 阅读附件中的论文，对每篇论文都生成一份中文 `.tex` 文件。最终只上传
一个 zip 作品压缩包，同时包含 skill 和论文解读，不再分开上传。

### 作品压缩包结构

压缩包解压后必须直接得到以下结构，根目录不得再套一层外部文件夹：

```text
submission.zip
├── skill/
│   ├── SKILL.md
│   └── ...                 # skill 需要的其他文件或目录
└── summaries/
    ├── <论文 1 的 PDF 主文件名>.tex
    ├── <论文 2 的 PDF 主文件名>.tex
    └── <论文 3 的 PDF 主文件名>.tex
```

- skill 入口必须是 `skill/SKILL.md`，大小写与文件名均不得修改。
- 每篇附件 PDF 必须在 `summaries/` 下对应且仅对应一个 `.tex` 文件。
- `.tex` 文件名必须与对应 PDF 的主文件名完全一致。例如附件为
  `paper-a.pdf`，则作品包内必须是 `summaries/paper-a.tex`。
- 论文解读 `.tex` 必须直接放在 `summaries/` 下，不得放入更深的子目录。

提交格式可以参考附件 `example.zip`。

**如果您提交的 skill 无法复现您提交的答案，您的成绩可能会被设为 0 分**。

此外，我们建议您设计一个 **通用** 的 skill，不要对附件中的几篇论文做专门的适配，这样一来，您平时就可以用这个 skill 来阅读任意的数学论文。

---

### 评分模式

只要您的 skill 文件完整、tex 文件使用中文且可用 `xelatex` 编译、对论文的解读清晰易懂，您本次作业就能获得满分。

排行榜使用 **ELO 动态评分机制**：定时抽取两份不同用户的作品，用大模型进行偏好选择，被评为 “更优” 的用户会涨分，另一个用户会掉分。**排行榜与作业成绩无关，只是用于选出最佳 skill 供大家参考。**

---

### 评分详情

您可以在 “对战数据” 里看到大模型对您和其它人的解答进行偏好选择的结果。由于裁判模型具有位置偏好（答案质量相近的情况下，偏好第一份答案），我们对每个解读进行两次评分，顺序分别为 `(A=1, B=2)` 与 `(A=2, B=1)`，其中 `1` 是 “对战数据” 中左侧的选手。
