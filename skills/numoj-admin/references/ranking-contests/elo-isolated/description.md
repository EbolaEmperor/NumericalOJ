你需要编写一个 Bot，在随机生成的中心对称棋盘上与另一位选手同时移动。每走一步，身后的格子都会封死；尽可能比对手更晚陷入无路可走的境地。

## 棋盘与初始状态

- 每场对战独立随机生成一个 `n × n` 棋盘，`7 ≤ n ≤ 20`。
- 坐标使用 `[row, col]`，左上角是 `[0, 0]`；`row` 向下增加，`col` 向右增加。
- 大约 10% 的格子是黑格障碍。全部初始障碍关于棋盘中心对称：若 `[r, c]` 是障碍，则 `[n-1-r, n-1-c]` 也是障碍。
- A 方从左下角 `[n-1, 0]` 出发，B 方从右上角 `[0, n-1]` 出发。起点及其初始可移动邻格不会生成障碍。
- 每场对战使用不同的随机种子；棋盘尺寸、障碍和随机种子会显示在对战详情中。

## 回合规则

每一轮，双方都基于同一个“移动前局面”作出决策：

1. Bot 必须选择向上、下、左、右相邻的一个白格移动一步。
2. 对手当前所在的格子不算白格，不能移动到那里，因此双方不能交换位置。
3. 裁判按 **A 方、B 方** 的顺序分别调用两个 Bot；两次调用互不并行，每一方各自最多有 1 秒思考时间。
4. 收齐双方决策后，裁判才会同时应用两次移动。移动成功后，双方原本所在的格子都变成黑格。
5. 如果双方选择了同一个白格作为目标，则双方同时进入该格，本局立即以平局结束。
6. 每轮开始时，若仅一方没有合法移动，该方立即失败；若双方同时没有合法移动，则本局为平局。
7. 超时、进程退出、输出格式错误或选择非法移动均视为本轮决策失败。仅一方失败时另一方获胜；双方同轮都失败时为平局。

## 提交格式

只上传一个 ZIP 作品包。压缩包解压后的根目录必须直接包含：

```text
submission.zip
└── bot.py
```

Bot 使用 Python 3 和标准库运行。进程会在一次对战中常驻，不会每轮重新启动。

## Bot 通信协议

### 1. 启动握手

Bot 启动后应在 10 秒内向标准输出写一行 JSON，并立即刷新缓冲区：

```json
{"ready": true}
```

### 2. 接收局面

之后，Bot 每次从标准输入读取一行 JSON。示例：

```json
{
  "type": "turn",
  "version": 1,
  "side": "A",
  "round": 0,
  "n": 9,
  "board": [
    "........B",
    ".........",
    "...#.....",
    ".........",
    "....#....",
    ".........",
    ".....#...",
    ".........",
    "A........"
  ],
  "you": [8, 0],
  "opponent": [0, 8],
  "legal_moves": [
    {"move": "U", "to": [7, 0]},
    {"move": "R", "to": [8, 1]}
  ]
}
```

`board` 中：

- `.` 表示可进入的白格；
- `#` 表示初始障碍或已经走过的封闭格；
- `A`、`B` 表示双方当前位置。

`legal_moves` 已列出当前全部合法选择，建议直接从中选择。

### 3. 输出决策

Bot 必须在收到局面后 1 秒内向标准输出写一行 JSON，并立即刷新：

```json
{"move": "U"}
```

`move` 只能是 `U`、`D`、`L`、`R` 之一，并且必须出现在本轮 `legal_moves` 中。

标准输出只用于协议；调试信息请写入标准错误。每次输入只允许对应一行输出。

## 最小随机 Bot 示例

```python
import json
import random
import sys

print(json.dumps({"ready": True}), flush=True)

for line in sys.stdin:
    message = json.loads(line)
    if message.get("type") == "end":
        break
    choice = random.choice(message["legal_moves"])
    print(json.dumps({"move": choice["move"]}), flush=True)
```
