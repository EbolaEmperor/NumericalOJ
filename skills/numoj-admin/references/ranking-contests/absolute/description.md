# 图片批改练习赛：公开题目描述

在参加本赛事之前，请先完成题目：[学号 bmp](http://10.72.190.121:2025/problem/71)。

附件 `demo.py` 展示了系统的评分流程：将评分标准、用户的学号写进提示词，并将用户生成的图片作为附件，调用 Qwen API 来获取 AI 评分结果。

在评分过程中，我们发现一些奇怪的图片也能通过 AI 评测，比如下面两个图片：

<img src="http://10.72.190.121:2025/static/figures/3240100672.png" style="width:400px"></img>
</center>

这是学号为 `3240101905` 和 `3240100672` 的同学上传的图片，AI 会将上述图片判定为 **`答案正确`**。

本次比赛需要您重新设计一个评测流程（方法不限），并用您设计的评测流程对附件中 `test.zip` 内的图片进行评分：

- 图片的文件名是提交者的学号；
- 图片的内容是提交者所提交的图片。

您需要将评分结果保存为 `test.json`，格式与附件中的 `demo.json` 一致。

---

### 提交要求

您一共需要提交两个文件：

1. 一个 `.json` 文件，包含您的评测流程对 `test.zip` 内所有图片的评分结果，格式需与 `demo.json` 一致。
2. 一个 `.zip` 文件，里面包含您的评测流程所需的一切代码，以及一个 `README` 文件说明您的评测方案。

对于代码中涉及到 `API-KEY` 或密码等隐私数据的位置，请您用 `****` 代替，以免个人信息泄露。

请务必确保您的 **评测流程可以完整复现评测结果**，我们会对所有代码进行抽测，得分越高的代码越容易被抽测，**无法复现的代码将被设为 0 分**。

本题的目的是练习 API 的使用、提高您的工程水平，因此 **请不要过拟合测试集或人工标注数据。**

---

### 评分标准

您所提交的文件中，`reason` 字段不作为评分标准。唯一的评分标准是您的 `score` 与人工打分的 `score` 是否匹配。人工打分的 `score` 保存在系统后台，不对外公布。

`test.zip` 中共有 100 组数据，每组数据 1 分，满分为 100 分。

只要您获得 **70 分以上**，本次作业就记为**满分**。冠军还将获得价值 300 元以上的 **神秘礼品**。

**Update Apr.23：**  为防止过拟合测试数据，我们不以榜单作为评判冠军的唯一标准。我们另外准备了一套 **不公开** 的数据集，我们会在该数据集上运行 **95 分及以上** 的代码，测出最高分作为冠军。
