## 问题描述

核心任务：从地球表面发射一枚火箭，使其先借助月球的引力做一次速度修正，进入一条日心椭圆转移轨道；火箭沿该椭圆飞行，绕过太阳，即经过近日点后，沿椭圆另一支返回到地球轨道，要求与地球在空间中相遇(至少小于地球的SOI)。

目标是在 2026 年一年内寻找一个最优发射日期 $t_0$，使所需的总速度增量 $\Delta v_{\mathrm{total}}$ 最小。

$$\Delta v_{\mathrm{total}}(t_0,r_m,\mathrm{side},r_p)=|\Delta v_{\mathrm{发射}}|+|\Delta v_{\mathrm{月借残差}}|+|\Delta v_{\mathrm{再入}}|$$

其中：

$\Delta v_{\mathrm{发射}}$表示从地球表面到月球 SOI 边界所需的初始脉冲速度；

$\Delta v_{\mathrm{月借残差}}$ 表示理想被动借力之外为校正轨道所需的微小修正脉冲，理想情况下趋近于 0；

$\Delta v_{\mathrm{再入}}$表示返回时使火箭与地球轨道相切并减速至再入速度所需的脉冲。

$t_0$取 2026-01-01 至 2026-12-31，步长为 1 d；

$r_m\in [R_{\mathrm{moon}}+100,50000]$ km，表示月球借力时与月心的最近距离；

$\mathrm{side}\in\{\mathrm{leading},\mathrm{trailing}\}$，表示从月球运动方向的前侧或后侧绕过；

$r_p\in[2R_{\mathrm{sun}},0.4r_1]$，表示日心椭圆的近日点距离。

任务约束如下：

**C1：**$r_m\ge R_{\mathrm{moon}}+100=1838$ km，且 $R_{\mathrm{moon}}=1737.4$ km，避免撞月；

**C2：**$r_p>R_{\mathrm{sun}}=6.96\times 10^5$ km，避免撞日；

**C3：**总飞行时间 $T_{\mathrm{total}}\le 2$ 年；

**C4：**再入相对速度 $v_\infty\le 15$ km/s；

**C5：**N 体仿真总能量相对漂移在一年内不超过 $10^{-6}$。

**数学模型要求：**理论框架采用钱学森《星际航行概论》第 5–6 章拼接圆锥曲线法；月球借力在月球作用范围内视为月心二体双曲线轨道，SOI 约为 $6.6\times 10^4$ km，进出 SOI 时做坐标变换；N 体仿真模型为太阳、地球、月球、火箭，火箭质量忽略不计，作为试探粒子；参考系采用 J2000 黄道平面投影二维模型，单位为 km、s；历表来源为 JPL Horizons 系统或课程提供的数据缓存。

**推荐数值方法：**积分器推荐 Velocity-Verlet 二阶辛积分器，主步长 $h=3600$ s，事件细化阶段可减至 $h=60$ s。您也可自行选择 RK4、辛 Yoshida 四阶等其他积分方案，但须在报告中说明选择理由与守恒性验证。优化算法推荐外层 365 个发射日期粗扫描，加内层 $(r_m,r_p)$ 参数网格搜索，并用黄金分割或二分等方法精化。建议每 1000 步检查总能量与角动量相对漂移并记录日志。

**推荐编程环境：**`Python 3.10+`；如使用 `C/C++`、`Julia`、`MATLAB` 等其他语言，须自行解决 `Horizons` 接入与 `LaTeX` 集成。推荐包包括 `numpy`、`scipy`、`matplotlib`、`astroquery`、`astropy`；视频生成可使用 `ffmpeg`；可使用课程提供的 `Teaching conda` 环境。允许使用 Claude Code、Cursor、Copilot 等 AI 工具，但须在致谢和 `AI-Agent.md` 中如实声明。

## 基础要求

1. **拼接圆锥曲线代码化：** 将现有 `report.tex` 中§3–§5 的步骤一至步骤六编码为可调用函数，输入近日距 $r_p$、地球轨道半径 $r_1$、日心引力常数 $K_s$ 等参数，输出椭圆轨道根数与速度增量。要求与现有 $r_p=0.2\ \mathrm{AU}$ 算例数值偏差不超过 0.1%。

2. **N 体数值积分器：** 实现 Sun-Earth-Moon-Rocket 四体的数值积分模块，提供加速度计算、单步推进、整段传播三个核心接口。在二体圆轨道基准 $\mu=4\pi^2$ 的无量纲测试中，验证 1 年内位置相对误差不超过 $10^{-4}$。

3. **JPL Horizons 历表对照：** 仅用 N 体传播 Sun-Earth-Moon 一年，与 JPL Horizons 历表对比，输出每日位置与速度残差，要求所有天体位置残差不超过 6000 km。Horizons 查询必须使用 `CENTER='@10'` 等质心写法，而不是 `CENTER='10'` 这类地面观测站写法。

4. **月球借力解析与数值实现：** 实现月球借力的解析公式，即双曲线偏折模型；同时实现数值仿真版本，并进行对比验证。实现中需要处理月心系、地心系、日心系之间的坐标变换，并支持 leading 与 trailing 两种绕飞方向。

5. **单点轨道求解：** 在固定发射日期下求解满足任务约束的完整轨道，输出三段 $\Delta v$ 数值，与无月球借力情况对比，并记录节能比例。

6. **一年周期最优发射窗口扫描。** 在 2026 年 365 个日期上扫描，对每个日期做内层参数精化，输出 $\Delta v_{\mathrm{total}}(t_0)$ 曲线与 $(t_0,r_p)$ 等值线，报告最优发射日期 $t_0^\ast$、对应 $r_m^\ast$、$r_p^\ast$ 与最小 $\Delta v_{\mathrm{total}}^\ast$。

7. **灵敏度与误差分析：** 围绕最优解做近月距、发射日期偏移、积分步长三方面的灵敏度或收敛性分析。

8. **可视化与展示：** 生成静态图，包括轨道、能量守恒、扫描曲线、残差等；并生成一段 30–60 秒的轨道动画 MP4，含关键事件 zoom-in。

## 加分方向

1. **3D 扩展：** 把 2D 仿真扩展到 3D，纳入月球 $5.1^\circ$ 轨道倾角，分析其对最优窗口的影响。

2. **相对论修正：** 在近日点附近加入广义相对论修正项，形式约为 $3\mu^2/(c^2r^4)$，定量分析其对轨道的影响。

3. **自定义微分修正器：** 不使用 `scipy.optimize`，自行实现 Newton-Raphson 微分修正或 Lambert 求解器。

4. **多次借力：** 探索 Earth → Moon → Venus → Sun → Earth 等更复杂的多次借力轨道。

5. **实时交互演示：** 仿照 `week9/src/two_body_realtime.py` 风格，做一个 Tkinter 或 Web 实时交互演示。

6. **其他创新：** 任何与项目主题相关、有思考深度的扩展，例如机器学习辅助轨道设计、并行计算加速扫描等。
