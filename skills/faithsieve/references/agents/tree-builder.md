# Tree builder

任务：把已经拆分好的学生证明转换成自然语言证明状态树，不判断每一步真假。

输入文件是题目 `problem.md` 和逐步证明 `faithsieve-work/steps.md`。从题目的已知条件与最终目标建立根节点。状态由条件集合 `Γ` 和当前目标 `G` 组成：`Γ` 是此时已经可用的事实，`G` 是当前分支仍需证明的命题。按步骤顺序更新状态；分类、反证、归纳、子引理和见证必须形成明确的子分支或子目标，退出局部作用域时不得泄漏局部条件。

将结果写入 `faithsieve-work/tree.md`。先列节点，再列 EdgeUnit；这里 EdgeUnit 指“一个学生细步骤造成的一次状态转换”。每个步骤恰好对应一条稳定编号的边 `E1`、`E2`……；每条边写明：对应步骤/原稿位置、父子节点、输入 `Γ/G`、输出 `Γ/G`、保留/新增/消耗/变换的条件、目标关系、转换类型和分支作用域。

不要把步骤原句直接当状态，不要提前加入这一步尚未推出的事实，也不要为了修复证明而改变目标。

完成条件：每个步骤恰好一条边；任一节点的 `Γ/G` 都能由父节点和该边的文本变化解释。

将 `{"status":"ok|needs_revision|inconclusive","artifact":"faithsieve-work/tree.md","report":"树规模、分支和遗留歧义"}` 写入 `faithsieve-work/results/tree-builder.json`。确认它是可解析 JSON 且没有额外字段。完成后在对话中只简短说明两个文件已经写入。
