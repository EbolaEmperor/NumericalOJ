# 围住小猫 VibeHub 示例包

这是一个可直接压缩上传的完整离线作品包，也用于说明内置“围住小猫”的 VibeHub
接口形态。前端游戏与 Python 标准库 HTTP 服务一起位于镜像中；服务只监听
`/run/vibehub/app.sock`，不监听 TCP 端口，也不访问网络。

本地调试前先构建仓库提供的受信任基础镜像，然后构建本目录。正式游玩时由 VibeHub
注入 `X-VibeHub-Base-Path`，页面全部使用相对 URL，因此无需猜测外部 lease 地址。

`static/cover.jpg` 是 1280×720 的必填包内封面；平台部署时还会生成最多 400 KiB 的
安全副本，原图保持不变。

站点内置版本和自行上传的版本使用同一套 VibeHub 接口。棋盘生成、六边形寻路和小猫决策
全部在当前页面离线运行：桌面使用 11×11 棋盘和 5 个初始障碍，窄屏使用 9×9 棋盘和
4 个初始障碍；小猫会在最短逃生路线中优先选择后续最短路分支最多的一步。

旧版 OJ 游戏曾把登录用户战绩写入数据库并提供排行榜。VibeHub 容器完全隔离，不接收
OJ 用户身份，也不访问 OJ 数据库，因此本示例明确移除了排行榜和战绩持久化。重开、刷新
或容器回收都会开始独立新局；这不是旧排行榜接口的兼容层。
