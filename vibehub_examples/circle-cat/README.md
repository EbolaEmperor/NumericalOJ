# 围住小猫 VibeHub 示例包

这是一个可直接压缩上传的完整作品包。它从 VibeHub 引入前的最后一版
NumericalOJ 围住小猫原样迁移：棋盘、布局、玩法和排行榜展示均保持一致。Python
标准库 HTTP 服务只监听 `/run/vibehub/app.sock`，不监听 TCP 端口，也
不访问网络。

本地调试前先构建仓库提供的受信任基础镜像，然后构建本目录。正式游玩时由 VibeHub
注入 `X-VibeHub-Base-Path`，页面全部使用相对 URL，因此无需猜测外部 lease 地址。

`static/cover.jpg` 是 1280×720 的必填包内封面；平台部署时还会生成最多 400 KiB 的
安全副本，原图保持不变。

桌面使用 11×11 棋盘和 5 个初始障碍，窄屏使用 9×9 棋盘和 4 个初始障碍；小猫会在
最短逃生路线中优先选择后续最短路分支最多的一步。棋盘和玩法完全在浏览器中运行；
胜利后玩家可以输入名字，将名字和回合数写入排行榜，也可以选择暂不记录。

排行榜保存在作品独享数据盘的 `/data/circle-cat.sqlite3`。作品不会获得 OJ Cookie、
用户名或数据库权限；数据盘只会挂载给当前作品，不与其它作品共享。排行榜接受浏览器
提交的胜利回合数，不提供服务端防作弊校验。
