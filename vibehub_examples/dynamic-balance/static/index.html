THE CHALLENGE

让每一轮，都刚好平衡。

实现 int step(int x)，接收传送带上的下一个整数，并返回所有已输入数字的中位数。

A.insert(x)向 A 插入 x
A.pop()删除 A 的堆顶，无返回值
A.top()读取 A 的堆顶

把 A 换成 B 即可操作另一棵堆。只提供这三个接口，请用全局变量记录大小。空堆不能调用 top 或 pop。

每轮结束时，需要同时满足
  1. 两堆恰好保存已经输入的所有数字。
  2. A 的大小等于 B，或比 B 多一个。
  3. A 中的每个数字都不大于 B 中的数字。
  4. 返回较小中位数：排序后第 ⌈n/2⌉ 个数。

试运行展示公开数据；正式提交使用新的隐藏数据，按照连续正确的轮数计分。输入范围为 −10⁹ 到 10⁹。
