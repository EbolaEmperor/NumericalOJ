# 动态平衡术

这是 `vibehub-edu/1` 协议的完整教学示例。平台的 `cpp-heap-median-v2` 执行器在
已启动的 VibeHub 作品容器内编译、运行学生代码，不再启动额外的判题容器。
执行记录仍由平台根据输入重放、核验，正式成绩来自冻结源码在隐藏输入上的重新执行。

学生实现 `double step(int x)`。`A` 是大顶堆，`B` 是小顶堆，均只提供 `insert(int)`、
`pop()`、`top()`、`size()`；`size()` 返回 `int`，空堆返回 0。调用之间全局状态保留。每轮结束时，
两堆应恰好保存已经输入的所有数，A 的元素数等于 B 或比 B 多一，且 A 中的所有数不大于 B。
函数返回当前中位数，偶数个元素时返回两个中间值的平均值。
堆元素仍是整数，返回值须为有限 `double`；求平均前先转换为 `double`。平台驱动以
`max_digits10` 精度记录返回值，避免整数截断或默认输出精度丢失。
旧的 `cpp-heap-median-v1` 保留 `int step(int x)` 和偶数取较小中位数的规则，
已有作业冻结的 v1 版本不受本示例升级影响。

试运行从平台取得真实 C++ 操作记录，用传送带及两棵二叉堆播放，遇到首个错误立即停下。
页面进入时弹出任务及 API 说明，确认后将同一张卡片动画停靠在代码区下方。
画面与试运行反馈不提前给出两堆大小或堆间顺序的解法条件，错误轮次保留预期值、返回值和运行异常。
正式提交由平台冻结源码、重新生成隐藏输入并评分，练习输入的通过情况不直接计入成绩。
公开浏览允许练习，只有作业入口绑定的作答可以记入老师的成绩表。

页面复用站点的 Monaco 编辑器及 C++ 高亮。`cd frontend && npm run build:monaco`
会同时生成本示例的离线编辑器资源；更新依赖或编辑器入口后需重新生成并一并发布。
编辑器以相对路径加载，不依赖外部 CDN，不改变作品 iframe 的权限。
两个服务分别监听 `/run/vibehub/app.sock` 与 `/run/vibehub/edu.sock`。
运行和评分均不接收用户学号，学生身份绑定由平台完成。
