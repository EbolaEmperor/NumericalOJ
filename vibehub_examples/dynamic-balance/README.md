# 动态平衡术

这是 `vibehub-edu/1` 协议的完整教学示例。作品只负责页面和评分规则，学生代码由
平台的 `cpp-heap-median-v1` 执行器交给普通判题 Docker 沙箱编译、运行，绝不在作品容器执行。

学生实现 `int step(int x)`。`A` 是大顶堆，`B` 是小顶堆，均只提供 `insert(int)`、
`pop()`、`top()`；可用全局变量记录两个堆的大小。调用之间全局状态保留。每轮结束时，
两堆应恰好保存已经输入的所有数，A 的元素数等于 B 或比 B 多一，且 A 中的所有数不大于 B。
函数返回排序后下标 `(n-1)/2` 的数，即偶数个元素时取较小中位数。

试运行从平台取得真实 C++ 操作记录，用传送带及两棵二叉堆播放，遇到首个错误立即停下。
正式提交由平台冻结源码、重新生成隐藏输入并评分，练习输入的通过情况不直接计入成绩。
公开浏览允许练习，只有作业入口绑定的作答可以记入老师的成绩表。

项目无需额外依赖。两个服务分别监听 `/run/vibehub/app.sock` 与 `/run/vibehub/edu.sock`。
运行和评分均不接收用户学号，学生身份绑定由平台完成。
