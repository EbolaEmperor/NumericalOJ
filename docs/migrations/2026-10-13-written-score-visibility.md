# AI 书面题评分公开开关

## 结构与行为

`problems` 新增 `written_score_public TINYINT NOT NULL DEFAULT 1`。现有题目保持
公开，不回填或删除评分数据。该字段仅控制书面题 AI 批改模式 1、2、3 的学生可见性；
管理员仍可读取完整结果。人工改分、AI 批改、最高分和 AC 的内部写入流程不变。

开关随题目创建、编辑的既有保存接口提交。旧客户端编辑时未提交该字段，服务端保留
当前值。关闭后，后续请求按题目当前策略隐藏全部历史和新提交的评分、评语、投票与
相关派生展示；开启后恢复。已被客户端读取或保存的信息无法收回。

## 发布前与发布

按 `docs/maintenance.md` 准备并验证备份和数据库回滚点。在一次性数据库运行
`scripts/init_db_schema.py --dry-run`，确认仅新增该列，然后同步结构并验证默认值。
完成后端单测与前端 typecheck、test、build。禁止在生产运行测试或为验证功能改写生产提交。

仅在用户明确授权部署后由 `deploy.sh` 统一执行结构同步与发布。生产只读验证：

```sql
SHOW COLUMNS FROM problems LIKE 'written_score_public';
```

## 回滚

结构属于仅添加列的变更，应用回滚时保留该列和全部评分数据，避免破坏已保存策略。
旧版本不识别隐藏开关，可能重新向学生返回隐藏成绩：存在关闭开关的题目时，不得直接
切回缺少评分可见性校验的应用版本，应先完成可审计的向前修复，或在维护窗口内保持
学生访问停止，按维护文档采用已验证的备份与恢复方案。
